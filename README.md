# Student Result Tracker

A Python-based Student Result Tracker that helps manage student records and results.

## Features
- Add Student
- View All Students
- Check Pass/Fail Status
- Search Student by Roll Number
- Delete Student Record
- Save Data to File

## Concepts Used
- Python
- Lists
- Dictionaries
- Loops
- Conditional Statements
- File Handling

## How to Run
1. Run the Python file.
2. Select an option from the menu.
3. Manage student records through the console interface.

# Expense Tracker

A Python-based Expense Tracker that helps users manage and monitor their daily expenses through a simple menu-driven interface.

## Features
- Add new expenses
- View all recorded expenses
- Calculate total spending
- Delete expenses
- Save expense data to a text file

## Concepts Used
- Python
- Lists
- Dictionaries
- Loops
- Conditional Statements
- File Handling

## How It Works
1. Add expense details such as date, category, description, and amount.
2. View all saved expenses.
3. Calculate total spending.
4. Delete unwanted expense records.
5. Save expense data to a file for future reference.

## Future Improvements
- Load saved expenses automatically on startup
- Search expenses by category
- Monthly expense reports
- Export data to CSV format
